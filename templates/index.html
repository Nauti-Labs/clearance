// the loop

Three parties. One flow.

Agent requests. Human approves. Any service verifies. No middleman holding the keys.

01 — Request

Agent asks for clearance

Your agent posts what it wants to do, the scope, and the budget. It gets back an approval URL instantly.

POST /v1/clearances
AI Agent
02 — Approve

Human taps yes (or no)

The human gets a clean mobile-friendly page showing exactly what the agent wants. One tap to approve or deny.

GET /approve/clr_a1b2...
Human
03 — Verify

Any service trusts the token

The agent gets a signed JWT proving approval. Any service verifies with one API call. No auth required to verify.

GET /v1/verify/{token}
Any Service
