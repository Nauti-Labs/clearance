What the integration looks like

Three surfaces matter: the bot request, the human approval, and the final verification gate before execution.

1. Bot creates a request

Before placing an order, the bot posts the action, scope, budget, and context to Clearance.

2. Human approves or denies

The approver gets a Telegram or browser prompt with the exact action and budget.

3. Bot verifies before execution

The bot verifies the signed token and refuses to trade if scope or budget does not match.

Drop this gate into any bot

Use these steps whether your bot trades crypto, bids on domains, buys ads, books travel, or triggers any expensive action.

STEP 01

Get an API key

Create a free Starter key from the homepage and store it in your bot environment as CLEARANCE_API_KEY. Do not hardcode it.

STEP 02

Wrap the risky action

Before a trade, create a Clearance request with a machine-readable scope such as trade:crypto:BTC:buy.

STEP 03

Wait for a decision

Send the approval URL to the human, rely on Telegram notifications, or poll /v1/clearances/{id} until approved or denied.

STEP 04

Verify before execution

Call /v1/verify/{token}. Only execute when the token is valid and the scope, budget, and currency match the pending action.

// python example

Minimal trading bot wrapper

Replace place_trade() with your exchange, broker, marketplace, or wallet execution function.

clearance_gate.py
import os
import time
import requests

CLEARANCE_BASE_URL = os.getenv("CLEARANCE_BASE_URL", "{{ base_url }}")
CLEARANCE_API_KEY = os.environ["CLEARANCE_API_KEY"]


def request_trade_clearance(symbol, side, platform, max_usd):
    response = requests.post(
        f"{CLEARANCE_BASE_URL}/v1/clearances",
        headers={"X-API-Key": CLEARANCE_API_KEY},
        json={
            "title": f"{side.upper()} {symbol} on {platform}",
            "description": f"Bot wants to {side} {symbol} with a max budget of ${max_usd}.",
            "scope": f"trade:{platform}:{symbol}:{side}",
            "budget_amount": max_usd,
            "budget_currency": "USD",
            "metadata": {
                "bot": "my-trading-bot",
                "symbol": symbol,
                "side": side,
                "platform": platform,
            },
        },
        timeout=10,
    )
    response.raise_for_status()
    return response.json()


def wait_for_decision(clearance_id, timeout_seconds=900):
    deadline = time.time() + timeout_seconds
    while time.time() < deadline:
        response = requests.get(
            f"{CLEARANCE_BASE_URL}/v1/clearances/{clearance_id}",
            headers={"X-API-Key": CLEARANCE_API_KEY},
            timeout=10,
        )
        response.raise_for_status()
        clearance = response.json()

        if clearance["status"] == "approved":
            return clearance["token"]
        if clearance["status"] in {"denied", "expired", "revoked"}:
            raise RuntimeError(f"trade blocked: {clearance['status']}")

        time.sleep(5)

    raise TimeoutError("trade blocked: no human decision before timeout")


def verify_clearance_token(token, expected_scope, max_usd):
    response = requests.get(f"{CLEARANCE_BASE_URL}/v1/verify/{token}", timeout=10)
    response.raise_for_status()
    verification = response.json()

    if not verification["valid"]:
        raise RuntimeError("trade blocked: invalid Clearance token")
    if verification["scope"] != expected_scope:
        raise RuntimeError("trade blocked: scope mismatch")
    if verification["budget_currency"] != "USD":
        raise RuntimeError("trade blocked: currency mismatch")
    if float(verification["budget_amount"]) < float(max_usd):
        raise RuntimeError("trade blocked: approved budget too small")

    return verification


def place_trade(symbol, side, platform, max_usd):
    # Your exchange, wallet, broker, or marketplace call goes here.
    print(f"EXECUTE {side} {symbol} on {platform} up to ${max_usd}")


def trade_with_clearance(symbol, side, platform, max_usd):
    expected_scope = f"trade:{platform}:{symbol}:{side}"
    clearance = request_trade_clearance(symbol, side, platform, max_usd)
    print("waiting for human approval:", clearance["approval_url"])

    token = wait_for_decision(clearance["id"])
    verify_clearance_token(token, expected_scope, max_usd)

    place_trade(symbol, side, platform, max_usd)
