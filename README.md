# Clearance — by Nauti-Labs

**Vessel clearance and maritime operations platform for ship agents and loss control professionals.**

Built by someone who spent 10 years managing chemical tanker agency operations on the Houston Ship Channel.

---

## What It Does

- **Vessel clearance workflow** — pre-arrival coordination, CBP form management, clearance tracking
- **Payment layer** — Stripe + USDC/Base for service billing
- **JWT auth** — secure, token-based access for agents and clients
- **Family/client dashboard** — real-time status visibility for vessel owners and charterers
- **Approval workflow** — human-in-the-loop clearance approvals

## Tech Stack

- Python / FastAPI
- SQLite (Railway-compatible)
- Stripe payments
- USDC/Base blockchain payments
- JWT authentication
- Docker / Railway deployment
